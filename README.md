# ESP32-CAM Advanced Firmware
## 📷 Расширенная прошивка с веб-интерфейсом и полным мониторингом

### ✨ Возможности

#### Основной функционал:
- 📹 **Видеопоток в реальном времени** - качественное MJPEG видео
- 📸 **Захват фото на SD карту** - сохранение снимков одним кликом
- 🌐 **Профессиональный веб-интерфейс** - современный дизайн с градиентами
- 📊 **Полный мониторинг системы** - все параметры в реальном времени

#### Мониторинг параметров:
- 🌡️ **Температура чипа ESP32** - с цветовой индикацией
- 📶 **WiFi сигнал (RSSI)** - качество соединения
- 💾 **Свободная RAM** - контроль памяти
- 💿 **Статус SD карты** - подключение и объём
- ⏱️ **Uptime** - время работы системы
- 🌐 **IP адрес** - сетевая информация
- 👥 **Количество подключенных клиентов** - мониторинг просмотров
- 🎬 **FPS видеопотока** - качество трансляции

#### Управление камерой:
- 📐 Разрешение (от QVGA 320x240 до UXGA 1600x1200)
- 🎨 Качество JPEG (10-63)
- ☀️ Яркость (-2 до +2)
- 🌓 Контраст (-2 до +2)
- 🎨 Насыщенность (-2 до +2)
- 💡 Встроенная вспышка (LED)
- 🔄 Перезагрузка системы

## 🛠️ Требования

### Аппаратное обеспечение:
- **ESP32-CAM** (AI-Thinker модель)
- **ESP32-CAM-MB** программатор (или USB-TTL адаптер)
- **Антенна** для WiFi (опционально, но рекомендуется)
- **microSD карта** (любого объёма, class 10 рекомендуется)
- **Блок питания 5V** (минимум 1A, рекомендуется 2A)

### Программное обеспечение:
- **Arduino IDE** 1.8.x или 2.x
- **ESP32 Board Support** версия 2.0.x или выше
- Драйвер **CH340** или **CP2102** (для программатора)

## 📥 Установка Arduino IDE и настройка

### 1. Установка Arduino IDE
Скачайте с официального сайта: https://www.arduino.cc/en/software

### 2. Добавление ESP32 в Arduino IDE

**Для Arduino IDE 2.x:**
1. Откройте `File` → `Preferences`
2. В поле "Additional boards manager URLs" добавьте:
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. Нажмите `OK`
4. Откройте `Tools` → `Board` → `Boards Manager`
5. Найдите `esp32` и установите **"esp32 by Espressif Systems"**
6. Дождитесь завершения установки

**Для Arduino IDE 1.8.x:**
1. Откройте `File` → `Preferences`
2. Добавьте тот же URL в "Additional boards manager URLs"
3. Остальные шаги аналогичны

### 3. Установка драйвера программатора

**Windows:**
- Для CH340: [Скачать драйвер](http://www.wch.cn/download/CH341SER_EXE.html)
- Для CP2102: [Скачать драйвер](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)

**macOS/Linux:**
- Обычно работает без дополнительных драйверов
- Для macOS может потребоваться: `brew install libusb`

## 🔧 Настройка и прошивка

### 1. Настройка WiFi

Откройте файл `ESP32_CAM_Advanced.ino` и найдите строки:

```cpp
const char* ssid = "YOUR_WIFI_SSID";        // ЗАМЕНИТЕ НА ВАШЕ
const char* password = "YOUR_WIFI_PASSWORD"; // ЗАМЕНИТЕ НА ВАШЕ
```

Замените на ваши данные:

```cpp
const char* ssid = "MoiWiFi";
const char* password = "moi_parol_123";
```

### 2. Настройка Arduino IDE

1. Подключите ESP32-CAM к программатору (или USB-TTL)
2. Вставьте программатор в USB порт компьютера
3. В Arduino IDE выберите:
   - **Board**: `AI Thinker ESP32-CAM`
   - **Port**: выберите COM порт (Windows) или /dev/cu.* (macOS)
   - **Upload Speed**: `115200`
   - **Flash Frequency**: `80MHz`
   - **Flash Mode**: `QIO`
   - **Partition Scheme**: `Huge APP (3MB No OTA/1MB SPIFFS)`

**Путь к настройкам:**
`Tools` → `Board` → `ESP32 Arduino` → `AI Thinker ESP32-CAM`

### 3. Прошивка

1. Вставьте microSD карту в ESP32-CAM
2. Нажмите кнопку "Upload" (стрелка →) в Arduino IDE
3. Дождитесь сообщения "Connecting..."
4. **ВАЖНО**: Если используете ESP32-CAM-MB программатор:
   - Нажмите кнопку `IO0` на программаторе
   - Удерживая её, нажмите `RST`
   - Отпустите обе кнопки
5. Прошивка начнётся автоматически
6. Дождитесь сообщения "Done uploading"

### 4. Первый запуск

1. Отключите USB от компьютера
2. Подключите ESP32-CAM к блоку питания 5V
3. Откройте Serial Monitor (`Tools` → `Serial Monitor`)
4. Установите скорость `115200 baud`
5. Нажмите кнопку `RST` на ESP32-CAM
6. В мониторе появится IP адрес камеры

Пример вывода:
```
ESP32-CAM Advanced Firmware v1.0
PSRAM found
Camera initialized
SD Card initialized
SD Card Size: 8000MB
Connecting to WiFi...
WiFi connected
Camera Ready! Use 'http://192.168.1.100' to connect
```

## 🌐 Использование

### Доступ к веб-интерфейсу

1. Откройте браузер (Chrome, Firefox, Safari)
2. Введите IP адрес из Serial Monitor: `http://192.168.1.100`
3. Откроется главная страница с видеопотоком

### Основные функции

#### 📹 Видеопоток
- Автоматически начинается при загрузке страницы
- Показывает FPS и количество подключенных клиентов
- Можно открыть в нескольких вкладках одновременно

#### 📸 Захват фото
1. Нажмите кнопку **"📸 Сделать фото"**
2. Фото сохранится на SD карту как `/photo_1.jpg`, `/photo_2.jpg` и т.д.
3. Появится уведомление об успешном сохранении

#### ⚙️ Настройки камеры
Все настройки применяются в реальном времени:
- **Разрешение**: выше разрешение = ниже FPS
- **Качество JPEG**: 10 = лучшее, 63 = худшее
- **Яркость/Контраст/Насыщенность**: регулируйте по вкусу

#### 💡 Вспышка
- Нажмите кнопку **"💡 Вспышка"** для включения/выключения
- Используйте для съёмки в темноте

#### 🔄 Обновление данных
- Статистика обновляется автоматически каждые 2 секунды
- Можно обновить вручную кнопкой **"🔄 Обновить"**

#### 🔌 Перезагрузка
- Кнопка **"🔌 Перезагрузка"** перезапускает ESP32-CAM
- Используйте при зависании или после изменения настроек

## 📊 Описание параметров

### Системная информация

**IP адрес**
- Локальный IP в вашей сети
- Используется для доступа к камере

**WiFi сигнал (RSSI)**
- Измеряется в dBm (децибел-милливатт)
- `-30 dBm` = отличный сигнал
- `-67 dBm` = хороший сигнал
- `-70 dBm` = слабый сигнал
- `-80 dBm` = очень слабый сигнал
- Добавьте антенну если сигнал слабый

**Uptime**
- Время непрерывной работы с момента последней перезагрузки
- Формат: дни, часы, минуты

**Free RAM**
- Свободная оперативная память
- Нормально: 100-200 KB
- Если меньше 50 KB - перезагрузите устройство

**SD карта**
- ✅ Подключена - карта работает нормально
- ❌ Нет - проверьте подключение карты

### Температура чипа

🟢 **Зелёный индикатор** (< 60°C)
- Нормальная температура
- Система работает стабильно

🟠 **Оранжевый индикатор** (60-70°C)
- Тёплая температура
- Обеспечьте вентиляцию

🔴 **Красный индикатор** (> 70°C)
- Горячая температура
- Уменьшите разрешение или FPS
- Добавьте радиатор или вентилятор

### Для высокого качества (низкий FPS)
- Разрешение: **UXGA (1600x1200)**

- Разрешение: **SVGA (800x600)** или **VGA (640x480)**
- Качество JPEG: **10-15**

### Для максимального FPS
- Разрешение: **QVGA (320x240)**
- Качество JPEG: **20**
- Ожидаемый FPS: 20-25

## 🔍 Решение проблем

### ESP32-CAM не загружается
**Симптом**: Светодиод не мигает, нет вывода в Serial Monitor

**Решение**:
1. Проверьте питание (должно быть 5V 1-2A)
2. Убедитесь что SD карта вставлена корректно
3. Попробуйте без SD карты
4. Проверьте подключение к программатору

### Не подключается к WiFi
**Симптом**: "Connecting to WiFi..." бесконечно

**Решение**:
1. Проверьте правильность SSID и пароля
2. Убедитесь что WiFi 2.4 GHz (ESP32 не поддерживает 5 GHz)
3. Подключите антенну для лучшего сигнала
4. Переместите ближе к роутеру

### Ошибка инициализации камеры
**Симптом**: "Camera init failed with error 0x..."

**Решение**:
1. Извлеките и вставьте обратно камеру
2. Проверьте все подключения камеры
3. Проверьте настройки пинов в коде
4. Попробуйте другую камеру

### SD карта не определяется
**Симптом**: "SD Card Mount Failed" или "No SD Card attached"

**Решение**:
1. Проверьте формат карты (должна быть FAT32)
2. Попробуйте другую SD карту (лучше class 10)
3. Переформатируйте карту в FAT32
4. Убедитесь что карта полностью вставлена
5. Попробуйте карту меньшего объёма (до 32GB)

### Низкий FPS
**Симптом**: Видео лагает, FPS < 5

**Решение**:
1. Уменьшите разрешение
2. Увеличьте Quality (10 → 20)
3. Улучшите WiFi сигнал
4. Закройте другие подключения
5. Перезагрузите ESP32-CAM

### Высокая температура
**Симптом**: Температура > 70°C

**Решение**:
1. Уменьшите разрешение камеры
2. Увеличьте Quality JPEG
3. Добавьте небольшой радиатор на чип
4. Обеспечьте вентиляцию
5. Используйте корпус с отверстиями

### Браузер не открывает страницу
**Симптом**: "Unable to connect" или timeout

**Решение**:
1. Проверьте что компьютер в той же сети WiFi
2. Попробуйте `http://` вместо `https://`
3. Отключите VPN
4. Попробуйте другой браузер
5. Проверьте firewall

## 🔐 Безопасность

### Важно!
⚠️ **Камера не защищена паролем!**

Любой в вашей сети может:
- Смотреть видеопоток
- Делать фотографии
- Изменять настройки
- Перезагружать устройство

### Рекомендации:
1. Используйте только в доверенных сетях
2. Не открывайте порты на роутере
3. Не используйте в публичных WiFi сетях
4. Измените SSID и пароль WiFi на уникальные

### Для продвинутых пользователей:
Добавьте HTTP Basic Authentication в код для защиты паролем

## 🆘 Поддержка

### Полезные ссылки:
- ESP32-CAM документация: https://github.com/espressif/esp32-camera
- Arduino ESP32 форум: https://forum.arduino.cc/
- ESP32 русскоязычное сообщество: https://esp8266.ru/

### Технические характеристики ESP32-CAM:
- **Процессор**: ESP32-S (dual-core 240 MHz)
- **RAM**: 520 KB SRAM + 4 MB PSRAM
- **Flash**: 4 MB
- **WiFi**: 802.11 b/g/n (2.4 GHz)
- **Bluetooth**: 4.2 BR/EDR и BLE
- **Камера**: OV2640 (2 МП, до 1600x1200)
- **Питание**: 5V через USB или пины
- **Ток**: 160-260 mA (средний), до 1A (пики)
